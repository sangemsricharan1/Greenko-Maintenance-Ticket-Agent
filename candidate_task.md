# Candidate Task

Implement ticket classification, severity scoring, recommended next action, and simple agent-style routing logic.

Required final step: Deploy the completed app to Railway.


## Implemented in this submission
- Ticket classification using explicit keyword rules and TF-IDF similarity fallback.
- Explainable severity scoring.
- Probable root-cause hypotheses and recommended next actions.
- Sequential agent-style routing workflow with P1-P4 queues.
- FastAPI backend, HTML/CSS/JavaScript frontend, evaluation endpoint, tests and Railway deployment configuration.
