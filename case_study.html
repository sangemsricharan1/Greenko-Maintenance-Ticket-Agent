AI Agent for Maintenance Ticket Prioritization

Greenko Group – Project Assignment Set 4

Problem

Classify, prioritize and route maintenance tickets for renewable-energy assets.

Solution flow

Ticket input → NLP-assisted category suggestion → rule-based severity scoring → root-cause hypothesis → next action → team and priority routing.

Implementation

  • FastAPI backend and browser UI
  • TF-IDF similarity and explainable keyword/risk rules
  • Five-step agent-style local tool workflow
  • Leave-one-out retrieval smoke test and automated tests

Limitations

The bundled dataset has six labelled examples. Results are a prototype only; human review is required. The workflow does not use an LLM or RAG and is not an autonomous agent.

Run the application using the commands in README.md and open http://127.0.0.1:8000.
